# LumenVerbi

Het Woord in jouw eigen taal. Upload een preek; LumenVerbi vertaalt hem bijna letterlijk naar de gekozen taal en maakt er een PDF van.

Talen: Nederlands, Engels, Kiswahili, Servisch, Arabisch, Syrisch, Perzisch (Farsi), Urdu (Pakistaans), Tigrinya, Oekraïens en Turks.

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- Node 22
- Zet de omgevingsvariabele `XAI_API_KEY` (alleen server, nooit in de browser). Zonder die sleutel kan de site geen preek vertalen.
